Review date: 12 October 2026. This audit records technical evidence and required attribution; it does not choose the owner's application license.

For Apache-licensed software and weights, include license texts, retain relevant attribution/NOTICE, and document modifications when redistributing modified upstream files. No upstream files or weights are modified. For permissively licensed dependencies, keep their copyright/license/disclaimer materials with source and binary distributions. These obligations do not resolve the missing application license.

For weather displays/exports, show [Weather data by Open-Meteo](https://open-meteo.com/) and a [CC BY 4.0 link](https://creativecommons.org/licenses/by/4.0/), name the reanalysis producer from the manifest, and state the transformations. The initial pipeline requests ERA5, so its metadata should credit ECMWF/Copernicus. The data are historical gridded reanalysis rather than independent local station truth. Attribution does not imply meteorological or telecom endorsement.

Keep the acquired model card, Apache license files, bootstrap revision/hash manifest, dataset manifests, dependency inventory, and generated evaluation report together when packaging a demo. `weather-ml-mcp/ATTRIBUTIONS.md` supplies concise credits; it is not a substitute for full license texts. The Docker Desktop exception and unresolved root license must remain visible in the implementation acceptance report.

The model card describes a roughly 28M-parameter pretrained time-series model and a DataFrame forecast interface. Local CPU inference uses that interface. The training corpus includes public time-series datasets; the card does not establish a definitive no-overlap cutoff for this Malaysian replay. Do not infer that a later replay date proves absence of pretraining leakage.

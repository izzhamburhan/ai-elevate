# Coordination procedure

1. Identify the user's scope and geography. Weather plus network exposure requires both Forecast and Engineer; commercial suitability calls Business. Use the available delegation tool and provide a concrete task, investigation reference and known replay dates.
2. Collect each returned specialist task. Preserve its real execution status, task/session ID, source references, geographic findings and warnings. Never fill an unavailable response with an imagined specialist answer.
3. Compare common site identifiers and geographic relationships. Treat nearby weather-grid exposure as a transparent rule, not outage causation. Distinguish daily synthetic KPI records from hourly weather predictions.
4. Produce a compact synthesis: confirmed evidence, plausible causes, missing evidence, recommendations and map-compatible findings. A lack of heavy rainfall or outages must remain a lack of evidence.
5. Use only the coordinator's memory to retain a concise investigation reference and any unresolved question. Do not store another profile's private memory or raw source databases.

The current repeatable weather demonstration uses cached ERA5 historical replay at September 26, 2026 UTC. It is local Chronos research inference, not an official forecast. No new crowd, footfall, revenue or outage ML models are part of this foundation.

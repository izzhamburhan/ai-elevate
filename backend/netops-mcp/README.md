# netops-mcp

FastMCP server exposing 62 network-operations tools (coverage, sites, tickets, BIN analytics,
subscriber analytics, next-best-action advisory, RAN KPI), backed by a **synthetic DuckDB database**,
plus a search over **real Malaysian places** (Overture Maps) and **real state/district/mukim boundaries**
(geoBoundaries).
Table and column names mirror the production source systems (map API, BIN visualisation, THD
reporting/ticketing, NBA collector), so queries and response shapes carry over to the real services.

## Quick start

```bash
uv sync
uv run python -m netops_mcp.seed                   # builds data/netops.duckdb (~30 s)
uv run python -m netops_mcp.seed.places            # downloads data/places_my.parquet (~78 MB, ~3 min)
uv run python -m netops_mcp.seed.boundaries        # downloads data/boundaries_my.parquet (~13 MB, ~20 s)
uv run python -m netops_mcp.server --http          # MCP: http://127.0.0.1:8000/mcp
```

## REST access (Postman, curl, browser)

The HTTP server also exposes every tool as a plain REST endpoint:

| Route | What |
|---|---|
| `GET /api/<tool>?arg=value` | Call a tool with query parameters (tools whose arguments are all simple values) |
| `POST /api/<tool>` | Call any tool; JSON body = its arguments |
| `GET /api/tools` | Tool names, descriptions and input schemas |
| `GET /geojson/<tool>?arg=value` | Only the tool's `geojson` FeatureCollection, CORS open (map clients load it by URL) |
| `GET /openapi.json` | OpenAPI spec: **Postman → Import → Link** to get one request per tool |
| `GET /docs` | Swagger UI |

```
GET  http://127.0.0.1:8000/api/get_ntt_tickets?technology=4g&status=open&page_size=5
POST http://127.0.0.1:8000/api/get_bins_in_area   {"mode": "cluster", "cluster": "Bangsar"}
```

Errors return HTTP 400 (validation), 403 (write disabled), 404 (not found) with
`{"ok": false, "error": {"code", "message"}}`.

The Elevate frontend lists this server as a built-in **NetOps** connector (chat composer → sliders
button), so starting it is enough. If it runs elsewhere, set the URL in `frontend/.env.local`:

```
NEXT_PUBLIC_NETOPS_MCP_URL=http://localhost:8000/mcp
```

Other modes:

```bash
uv run python -m netops_mcp.server                 # stdio (Claude Desktop / Claude Code)
uv run python -m netops_mcp.server --http --search # BM25 tool search: list_tools -> search_tools + call_tool
```

> Use `python -m ...` rather than the `netops-mcp` / `netops-mcp-seed` console scripts: on this machine
> Windows blocks the generated `.exe` shims ("Access is denied").

Stop the server before re-seeding — DuckDB allows one writer per file.

| Env var | Default | Purpose |
|---|---|---|
| `NETOPS_DB_PATH` | `data/netops.duckdb` | Database file |
| `NETOPS_PLACES_PATH` | `data/places_my.parquet` | Real place data for `search_locations` |
| `NETOPS_BOUNDARIES_PATH` | `data/boundaries_my.parquet` | Real boundaries for the admin-area tools |
| `NETOPS_REF_DATE` | today | Seed only: the "today" all synthetic dates are generated around |
| `NETOPS_SEED` | `42` | Seed only: random seed (data is reproducible for a given seed + ref date) |
| `NETOPS_READ_ONLY` | unset | `1` disables every write tool |
| `NETOPS_MCP_HOST` / `NETOPS_MCP_PORT` | `127.0.0.1` / `8000` | HTTP bind |

The reference date is stored in `_meta`, and tools treat it as "today", so defaults like "last 30 days"
always land on data even if the server runs weeks after seeding.

## Sample identifiers

| What | Value |
|---|---|
| IMSI / MSISDN (default subscriber, Petaling Jaya) | `502153000002017` / `601110002356` |
| 4G sites | `get_sites(technology="4g", region="Central")`, e.g. KLCC cluster `CL_KL_01` |
| BINs | `search_bins(bin_id="3.1579,101.7123")` (BIN grids exist around urban clusters) |
| VIP tickets | `get_vip_tickets()` → `ctt2` like `VCTT/2026/9/412` |

## Conventions

- Coordinates are WGS84. `'lat,lng'` strings put latitude first; GeoJSON is `[lng, lat]`.
- **Every `radius` is in km** (the legacy BIN endpoints used metres; unified here).
- Paginated tools return `{total, page, page_size, total_pages, items}`; layer tools return a GeoJSON
  `FeatureCollection` (`geojson`) plus `total`.
- Tools never raise to the client. Failures return `{"ok": false, "error": {"code", "message"}}` with
  codes `validation_error`, `not_found`, `auth_error`, `upstream_error`, `internal_error`.
- Tools whose description says "omit X for the latest" return the chosen value plus
  `available_weeks` / `available_dates` / `available_range`.

## Dataset

Generated by `src/netops_mcp/seed/`; schema in [`src/netops_mcp/schema.sql`](src/netops_mcp/schema.sql).
38 TM clusters in all 6 regions → ~470 4G sites (~2,400 cells), ~100 5G, ~140 MOCN, ~290 2G/3G, 70 AOP;
~2,100 BINs around urban clusters; 8 weeks of coverage/congestion/EMS; 60 days of per-cell RAN KPI;
30 days of subscriber activity for 60 subscribers with daily home/commute/work routines.
Events are linked: open outage NTTs mark sites *Out of Service*, depress their KPIs and are what
`exclusion=true` removes; subscriber personas (poor indoor coverage, congested workplace, outage at home,
quota exhausted, VoLTE issue, barred, rural MOCN) drive the advisory tools.

## Real place data (location search)

`search_locations` and `list_location_categories` are the only tools over real data: every named place in
Malaysia from [Overture Maps](https://overturemaps.org) (~845k points of interest: shops, hospitals, schools,
malls, petrol stations, ...; plus ~17.7k areas: states, districts, towns, neighbourhoods). Use them to turn a
place name into coordinates, or to find places of a category near a site.

```
GET /api/search_locations?query=mid valley megamall
GET /api/search_locations?query=hospital shah alam
GET /api/search_locations?category=hospital&state=Pulau Pinang
GET /api/search_locations?category=gas_station&lat=3.1579&lng=101.7123&radius_km=2
GET /api/list_location_categories?search=school
```

- `query` words are matched literally (no wildcards) against name, alternate names, brand, category,
  address, postcode and state; **all** words must match. Exact name matches rank first, then name prefix,
  then names containing the query; areas rank before places.
- `state` is assigned from the state boundary each point sits in, so it is always one of the 16
  states/federal territories (e.g. `Kuala Lumpur`, `Pulau Pinang`, `Labuan`).
- Refresh with `uv run python -m netops_mcp.seed.places` (latest release) or `--release 2026-09-23.1`.
  It stages the download in `data/places_my.staging.duckdb`, so a failed run resumes without downloading
  again. The file is read per query, so restarting the server is not needed after a refresh.
- Quality is Overture's: some duplicates and mis-categorised entries (e.g. an office tagged `gas_station`).
- Attribution: © Overture Maps Foundation, © OpenStreetMap contributors (CDLA-Permissive-2.0 / ODbL).

## Real administrative boundaries

`lookup_admin_area`, `list_admin_areas` and `get_admin_boundary` work on real Malaysian boundaries from
[geoBoundaries](https://www.geoboundaries.org): the country, 16 states/federal territories, 159 districts
(daerah) and ~2,040 mukim (incl. bandar/pekan town areas and Sarawak land districts).

```
GET  /api/lookup_admin_area?lat=3.1073&lng=101.6067          -> Selangor (MY-10) / Petaling / Bandar Petaling Jaya
POST /api/lookup_admin_area  {"points": ["3.1579,101.7123", "5.9804,116.0735"]}   (max 500 points)
GET  /api/list_admin_areas?level=district&parent=Selangor
GET  /api/get_admin_boundary?name=Selangor&detail=low        -> GeoJSON FeatureCollection
GET  /api/get_admin_boundary?level=district&parent=Johor
```

- `lookup_admin_area` is point-in-polygon on the full-detail shapes (~10 ms a point, 500 points in under 1 s).
  Points up to ~5 km outside every polygon (offshore) get the nearest area plus `nearest_km`; near a land
  border those may really be in Singapore, Thailand, Brunei or Indonesia.
- State names match `search_locations` (`Melaka`, `Pulau Pinang`); English names and common spellings work as
  aliases (`Malacca`, `Penang`, `KL`, `Hulu Langat`, `Kulai`).
- `get_admin_boundary` simplifies polygons by default (`detail=low`: Selangor ~3 KB; `medium` ~10 KB;
  `full` ~170 KB), since the result goes through the model's context. Over HTTP it also returns
  `geojson_url` (`/geojson/get_admin_boundary?...`); with `include_geometry=false` the model gets only the area
  list and hands that URL to `kepler_load_data`, so the map fetches the polygons itself instead of the model
  copying coordinates (Johor's districts: ~20 s and 4 tool calls instead of ~2 min and 11). Set
  `NETOPS_PUBLIC_URL` if the browser reaches this server at another address than `http://<host>:<port>`.
- The three levels come from different sources, so borders can disagree by a few hundred metres; lookups say so
  in `note` (~1% of points). The source has no Sabah/Sarawak divisions (bahagian), no Sabah mukim, and no
  Putrajaya district (the district data includes Putrajaya in Sepang).
- The source files have no hierarchy: the seed assigns each district/mukim the parent it overlaps most, and
  splits mukim the source merged by name across districts (e.g. three different `Mukim Pulai`).
- Refresh with `uv run python -m netops_mcp.seed.boundaries`; the server reloads the file on its next call.
- Licences: states © OpenStreetMap contributors (ODbL 1.0); districts geoBoundaries/citypopulation.de
  (CC BY 3.0); mukim Wikimedia Commons (CC BY 4.0). All allow commercial use with attribution
  (ODbL also requires share-alike for derived databases).

## Where behaviour differs from the real services

- **Coverage/congestion layers** return plain GeoJSON (real: geobuf + base64) and accept
  `week` as `40` or `2026-W40`.
- **`get_visited_sites`** returns one row per visit with start/end times and site coordinates (for
  hour-level movement playback); real returns the latest 10 unique sites.
- **Coordinates added** to NTT, maintenance, congested-cell, worst-cell and top-cell responses.
- **`get_bins_in_area`** returns the BINs inside the area with KPIs plus the real per-layer site/PRB
  summary; the real endpoint returns only the summary.
- **`get_ntt_summary`** weekly/daily scopes compare real current vs previous windows (the legacy weekly
  variants return empty strings).
- **`get_mobile_dashboard_advisory`** picks the closest matrix row (weighted) instead of requiring an exact
  match, which almost never hits on live data.
- **RAN KPI** has no precedent: catalogue and thresholds are in `tools/ran.py`; `exclusion=true` drops
  site-days with an outage NTT or planned maintenance. Granularity is daily/weekly/monthly (no hourly data).
- **`verify_nba_api_data`** checks the NBA tables instead of calling jsonplaceholder.typicode.com.
- **`export_vip_tickets_csv`** returns the CSV text (max 5,000 rows) instead of streaming a download.
- Write tools are open (no JWT); set `NETOPS_READ_ONLY=1` to disable them.
